Pema pour ordinateur

Ton téléphone analyse chaque clip, ton ordinateur applique la couleur dans DaVinci Resolve. Rien ne quitte ton Wi-Fi, et ton étalonnage n'est jamais modifié.

Avant de commencer

DaVinci Resolve Studio (la version gratuite ne peut pas être pilotée). Dans DaVinci : Préférences → Système → Général → « External scripting using » : Local. Le téléphone et l'ordinateur sur le même Wi-Fi.

Installer

    Ensuite

    1. Une page s'ouvre avec l'adresse et le code (toujours sur http://localhost:8765, sur l'ordinateur).
    2. Dans l'app Pema → Outils → Mon ordinateur : entre l'adresse et le code, puis « Tester la connexion ».
    3. Choisis « Demander » ou « Tout seul » : Pema colore les clips de la timeline ouverte dans une version « Pema ».
    mmebatech — Pema. Pema pour ordinateur démarre avec l'ordinateur ; tu peux l'arrêter ou le désactiver depuis sa page.
